# Script Template — 25–35s Shorts

```
[0-2s]   HOOK        — strong curiosity statement
[2-8s]   DISCOVERY   — ordinary object / hidden door found
[8-25s]  REVEAL      — miniature world appears
[25-32s] TWIST       — small twist
[32-34s] QUESTION    — comment-baiting final question
```

Rules: very short sentences, simple English, no long narration, poetic but
clear, never childish or over-explained.

## Example (Video 001)

```
I opened the fridge at 3AM.
Behind the milk, something was glowing.
It was a train station.
A very small one.
Then a train arrived.
No driver. No passengers.
The ticket had my name on it.
Last stop: Tomorrow.
Should I get on?
```
