# Small Door Brand Bible

Source of truth: `data/channel_bible.md`. Read it before producing or judging
any content for this channel.

## What to enforce

- Not a kids' channel. No oversaturated cartoon look, no childish colors.
- No human faces, no real people, no celebrities, no brands, no logos, no
  copyrighted characters.
- Cinematic, cozy, mysterious, magical-realism atmosphere. Dark but warm.
- Every video: 25–35 seconds.
- Subtitles: short, English only.
- Every video must follow: ordinary object → hidden tiny world → twist →
  comment question.
- Every video must feel distinct: different object, different world,
  different sound, different twist than prior videos in `data/video_queue.csv`.

## How to use this skill

1. Before generating new ideas/scripts/prompts, re-read `data/channel_bible.md`.
2. When reviewing any draft (idea, script, scene prompt, metadata), check it
   against the bans and the five-part formula.
3. If something violates a hard ban, reject it and explain which rule it
   broke — do not soften or rationalize the violation.
4. When in doubt about tone, prefer mysterious/cinematic over cute/explanatory.
